## MoveToMonitorButton v0.1.13

- UIを英語・日本語に分離しました。メニュー、移動先ツールチップ、表示診断、通知・エラーを切り替えられます。
- 既定はWindowsの表示言語に従います。日本語以外では英語を使用します。トレイの「言語 / Language」で明示的に選べ、再起動せず反映し、現在のユーザーに保存します。自動選択にも戻せます。
- 英語版・日本語版READMEに、3画面以上で使う「前／次」2ボタンの実アプリ画像を追加しました。表示プレビューで撮影したことと撮影元を明記しています。

English and Japanese UI strings are now separate. Menus, tooltips, diagnostics, and notifications follow the Windows display language by default (Japanese, otherwise English). Choose **Language / 言語 → English / 日本語** in the tray menu for an immediate, persistent override, or return to automatic selection. Both READMEs now show an actual Windows Settings capture of the paired button layout, with its preview-capture scope and provenance.

旧版をトレイから終了してから新版に入れ替えてください。証跡・紹介用画像はGitHubに保持し、配布ZIPはEXE・短いREADME・LICENSE・チェックサムのみです。
