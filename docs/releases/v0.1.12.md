## MoveToMonitorButton v0.1.12

- 3画面以上の拡張表示では「前の画面」「次の画面」の2ボタンを表示します。2画面では従来どおり1ボタンです。
- 画面番号の昇順に移動し、最初・最後で循環します。右クリックによる移動先選択も同じ番号順です。
- ホバーすると移動先番号を表示します。Windows「識別」と自動取得の番号が違う環境では、「画面番号をWindowsに合わせる…」で補正して保存できます。Windows側の設定は変更しません。
- 2ボタンそれぞれの5点の当たり判定を検査し、HiDPIでの縦位置・非アクティブウィンドウの操作を維持します。押したボタンと離したボタンが異なる場合は移動しません。
- Settings・ChatGPT・ChatGPT Classicの1ボタン／2ボタン表示を、実際の100%・150%・200%スケールで検査します。厳密な2色preflightと既存の試験を継続し、両ボタンの描画・ホバー・10点の入力領域を公開前に確認します。

Automatic display numbering can differ from Windows Identify on some drivers. Use the number-correction menu when needed. Three or more extended displays get previous/next buttons in ascending number order; two displays keep one button. Both directions wrap around.
